# Алгоритм Кронекера: разложение многочленов на множители

Приложение на [Flet](https://flet.dev), которое раскладывает многочлен с целыми коэффициентами на неприводимые множители с помощью алгоритма Кронекера. 

В ходе проекта было реализовано 6 версий (+3 подверсии) алгоритма: от базовой версии до самой оптимизированной. Чтобы можно было сравнить, как оптимизации влияют на объём вычислений, все версии и подверсии доступны внутри приложения и их можно менять.

## Об алгоритме Кронекера

Метод Кронекера раскладывает многочлен `f(x)` степени `n` с целыми коэффициентами:

1. Выбирается `m = n // 2 + 1` целых точек `a₀, a₁, ...`. 
   Любой множитель степени не выше `n // 2` однозначно задаётся своими значениями в этих точках.
2. В каждой точке значение множителя должно быть делителем числа `f(aᵢ)`. 
   Перебираются все сочетания таких делителей с учетом знака.
3. Для каждого сочетания строится интерполяционный многочлен по формуле Лагранжа.
4. Если он целочисленный и делит `f(x)`, найден множитель. Процесс повторяется для остатка.

Цикл будет продолжаться до тех пор, пока исходный многочлен не станет равен 1.

## О приложении

Интерфейс состоит из 3 вкладок:

| Вкладка | Что делает |
|---|---|
| **Алгоритм** | Ввод многочлена. Запуск алгоритма. Показывает исходный многочлен и результат . Результат копируется одной кнопкой. Также выводится, сколько раз пришлось использовать формулу Лагранжа. |
| **База примеров** | Готовые примеры из `examples.json`. |
| **Версии** | Выбор версии алгоритма 1.0-6.0. По умолчанию выбрана 5.0, она считается самой стабильной. |

Главная метрика сравнения версий - число вызовов формулы Лагранжа.
Чем меньше, тем эффективнее версия.

## Оптимизации

Версии лежат в отдельных модулях `kronecker_algorithm_ver_*.py`. 

| Версия | Что изменилось по сравнению с предыдущей |
|---|---|
| **1.0** | Базовая реализация. |
| **1.1** | Сортировка делителей. |
| **1.2** | Симметричные точки: `0, 1, −1, 2, −2, …`. |
| **1.3** | Симметричные точки: `0, 1, −1, 2, −2, …`. Сортировка делителей. |
| **2.0** | Выбор «хороших» точек: берутся такие `aᵢ`, где значение `f(aᵢ)` ненулевое и имеет мало делителей. Найденные корни выносятся из многочлена сразу. |
| **3.0** | Быстрая проверка до построения многочлена Лагранжа: свободный член будущего множителя вычисляется по точкам и должен делить свободный член `f`. Лишние многочлены Лагранжа не строятся. |
| **4.0** | Выносится общий множитель коэффициентов. Перебор знаков сокращается вдвое: множители `g` и `−g` эквивалентны, поэтому достаточно половины сочетаний. Добавлен признак Эйзенштейна. |
| **5.0** | Признак Эйзенштейна подключён к основному циклу: если многочлен гарантированно неприводим, перебор прекращается сразу. Это версия по умолчанию. |
| **6.0** | Сначала ищутся рациональные корни среди делителей свободного члена. Каждый найденный корень понижает степень и уменьшает нужное число точек. Проверка Эйзенштейна в основном цикле не вызывается. |

## Запуск из исходников

Нужен Python 3.9+.

```bash
git clone https://github.com/<владелец>/<репозиторий>.git
cd <репозиторий>

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install "flet==0.28.3"
python main.py
```

Откроется окно приложения.

Запуск в браузере вместо окна:

```bash
flet run --web main.py
```

## Сборка под Windows, macOS и Linux (GitHub Actions)

Готовые приложения собирает workflow .

| ОС | Раннер | Результат |
|---|---|---|
| Windows | `windows-2022` | `build/windows` |
| macOS | `macos-latest` | `build/macos` |
| Linux | `ubuntu-24.04` | `build/linux` |

### Как запустить

Вкладка Actions => Build Flet app => Run workflow

### Зависимости для сборки

Список зависимостей берётся из `pyproject.toml`:

```toml
[project]
dependencies = ["flet==0.28.3"]
```

`requirements.txt` в проекте содержит полный `pip freeze`, и такой набор не нужно упаковывать в приложение.

### Локальная сборка

```bash
pip install "flet==0.28.3"
flet build windows    # или macos / linux
```

На Linux перед этим:

```bash
sudo apt-get install -y clang cmake ninja-build pkg-config \
  libgtk-3-dev libasound2-dev libmpv-dev mpv
```

## Запуск в Docker

В контейнере нет экрана, поэтому приложение работает как веб-сайт. 

```bash
docker build -t kronecker-app .
docker run --rm -p 8550:8550 kronecker-app
```

Откройте <http://localhost:8550>.

С Docker Compose:

```yaml
services:
  app:
    build: .
    ports:
      - "8550:8550"
    restart: unless-stopped
```

```bash
docker compose up --build
```
